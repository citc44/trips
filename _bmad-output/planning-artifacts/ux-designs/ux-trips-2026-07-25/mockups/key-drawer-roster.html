Direction: Wayfinder — Action Drawer Voyager Roster (Redesign)

Why: the shipped roster row (left frame) never had a real mockup behind it — key-live-map.html's own drawer-open frame only ever showed the three static menu rows (Grant/Remove/End Voyage as if they were simple actions, not a real per-person list), so the actual per-Voyager row was built without design guidance. The result: a plain-text name, an uppercase role label, a mismatched solid-fill "Grant Organizer" chip, and a bare underlined "Remove" link, all competing on one cramped line with no visual identity per person — exactly the "not professional" feedback.

What changed: each Voyager gets the same colored initial-avatar treatment their own map marker already uses (direct visual continuity with the map, not a new motif), with a crown badge for the Organizer. Name and role move to their own stacked lines instead of fighting for horizontal space. Role reads as a small tag (dark "Organizer" tag matching the marker's own tag chip; a teal "Driving" / neutral "Riding" tag, reusing the status pill's own teal). Grant/Remove become a matched pair of bordered pill buttons on their own row beneath the name — same button family as the rest of the app (button-secondary's bordered fog pill, button-destructive's coral-tinted pill) — instead of one solid chip and one bare underlined link that don't read as the same control family at all.

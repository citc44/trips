Direction A — "Road & Reveal"

Idea: Memory Lane visually rhymes with Home's own "Memory Sparks" promise instead of introducing a new visual world. Same road-and-glow grammar, same amber heartbeat, same rising sparks — Home was foreshadowing this exact moment, so paying it off in the same language should land as "the story completed itself."

Trigger screen: full-bleed accent-primary (the same register Voyage Intro and Join Invitation already use for the app's biggest emotional beats), amber heartbeat glow, sparks lifting off screen-bottom, "Show me my Voylo" CTA in white.

Opening card: the perspective road climbs into a full-bleed blue sky, destination name in display-hero, amber sun-glow at the vanishing point — same physical language as Home, now the hero rather than the background.

Finale: the three player-color dots — the same ones from Splash and Home — finally connect with a fully-drawn amber thread. app-icon's "Unfinished Loop" is deliberately never-quite-closed; this is the one moment in the whole app where it gets to close.

Constraint check: stays entirely within existing tokens — no new hues, no transparency/blur, reuses heartbeat/rise/roadDrift keyframes and sparkBurst/thread motifs already in the system.
